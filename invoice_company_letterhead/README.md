# Invoice Company Letterhead — Odoo 18 — V5.1

Based on stable V5.

Adds multi-page safe-area controls for the separate letterhead print:
- Letterhead Top Reserved Space (mm)
- Letterhead Bottom Reserved Space (mm)

These apply only to Print with Company Letterhead, helping invoice content
paginate above the stationery footer and below the stationery header.

Normal Odoo Print > PDF remains untouched.
