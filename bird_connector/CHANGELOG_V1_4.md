# Bird Connector V1.4 - Template Management

- New simple Odoo-first WhatsApp template editor.
- Draft -> Pending -> Approved / Rejected approval lifecycle.
- Submit templates to Bird / Meta from Odoo.
- Refresh approval status from Bird.
- Send Message is available only for Approved templates.
- Marketing / Utility / Authentication categories.
- Text and image header UI, body, footer, buttons and sample variables.
- Automatic WhatsApp channel-group lookup.
- Synced Bird templates remain supported.
- Existing message logs and delivery status features are preserved.
