# v1.9.69 - Infinite Scroll for Conversation History

- Open conversations with only the latest 40 messages instead of loading the entire history.
- Load 40 older messages automatically when the user scrolls near the top.
- Preserve the visible scroll position when older messages are prepended.
- Keep already loaded historical pages during realtime/status refreshes.
- Show a small loading indicator while fetching older history and a beginning-of-conversation marker when no older messages remain.
