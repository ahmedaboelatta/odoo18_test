# Bird Connector 1.9.12

- Conversations no longer auto-open the first record when entering the Inbox. A conversation opens only after the user explicitly selects it.
- This prevents an unread conversation from being marked/read simply because the Conversations menu was opened.
- Added a neutral WhatsApp-style landing state when no conversation is selected.
- Replaced the generic attachment picker with a small attachment menu containing **Document** and **Photo** options.
- Photo selection is restricted to images; Document selection accepts common office/PDF/text files.
- Existing multi-channel, media preview, close/reopen and live inbox behavior remains unchanged.
